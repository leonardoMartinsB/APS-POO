## ✨ Sobre o Projeto

Este projeto foi desenvolvido como parte de uma **Atividade Prática Supervisionada (APS)** na matéria de **Programação Orientada a Objetos (POO)**. O objetivo foi criar uma aplicação de desktop em **C#** que calcula a área e o perímetro de diferentes formas geométricas.

O grande destaque do projeto é a sua arquitetura, que foi totalmente baseada nos conceitos de **POO**, como herança, polimorfismo e encapsulamento, para garantir um código organizado, reutilizável e de fácil manutenção.

🔹 Principais destaques:

* ✅ Aplicação prática dos 4 pilares da **Programação Orientada a Objetos**
* ✅ Implementação de classes, objetos e herança para as diferentes formas geométricas
* ✅ Interface gráfica de usuário (GUI) intuitiva para interação
* ✅ Ótimo projeto para demonstrar o domínio de conceitos avançados de programação
